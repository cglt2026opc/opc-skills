# 四维八题与评分解释

## 评分方式

每题 0-10 分。书中表格标注 1-10 分；为兼容总分解释中的 0-29 区间，本技能把 0 定义为“尚未建立或无法提供任何事实依据”，有可评价表现时使用 1-10。0 是操作性补充，不改变书中分层。

| 支柱 | 题目 | 证据提示 |
|---|---|---|
| 产品思维 | 能独立完成从需求到交付的完整流程 | 最近一次独立项目、周期和结果 |
| 产品思维 | 能判断一个需求“该不该做” | 最近一次拒绝或降级需求的理由 |
| 主业深度 | 在专业领域能快速判断问题本质 | 最近难题、核心洞察和结果 |
| 主业深度 | 有客户愿意为专业能力付费 | 最近付费合作、金额或等价认可 |
| 第二技能 | 除主业外有其他能产生价值的技能 | 技能与最近创造的价值 |
| 第二技能 | 第二技能能与主业形成协同 | 放大主业价值的实际例子 |
| AI 杠杆 | 能用 AI 在 1 小时内完成以前 1 天的工作 | 同一任务前后耗时与质量 |
| AI 杠杆 | 有一套稳定的 AI 工作流 | 常用工具、环节、输入输出和复用频率 |

## 总分解释

| 总分 | 当前状态 | 书中建议 |
|---|---|---|
| 70-80 | 超级个体预备役 | 立即启动副业，3 个月内完成首单变现 |
| 50-69 | 能力具备，需整合优势 | 选择一个方向深耕，6 个月内打通商业闭环 |
| 30-49 | 基础扎实，需补齐短板 | 优先强化产品思维和 AI 杠杆，执行 90 天提升规划 |
| 0-29 | 仍在积累期，需系统学习 | 结合全书框架，在实践中积累真实证据 |

不要将区间外推为诊断、成功概率或收入预测。
