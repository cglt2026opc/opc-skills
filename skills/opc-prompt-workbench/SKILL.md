# OPC 提示词工作台

读取 [references/catalog.md](references/catalog.md) 选择场景。原版 16 个提示词保存在 `assets/AI赋能提示词模板库.docx`。

## 工作流

1. 明确任务结果、受众、可用资料、约束、输出格式和完成标准。
2. 选择最接近的模板；只读取或提取所需模板，不一次性加载整份文档。
3. 用用户事实替换占位符。缺失信息保留清晰占位符或最多追问三个关键问题，不编造案例、数据、价格或法律事实。
4. 把提示词改成可执行结构：角色与边界、输入、任务步骤、输出结构、质量检查、追问方式。
5. 输出“可直接复制版”，并附 1-3 条使用说明。用户要求执行时，再按提示词完成任务。

## 安全边界

- 情绪类模板只用于反思和行动梳理，不诊断、不替代心理治疗；出现自伤风险或持续影响生活时建议及时联系专业支持。
- 合同审查模板只做风险初筛，不能冒充执业律师意见；重要合同交由当地专业人士复核。
- 删除或泛化合同、客户、员工和健康资料中的敏感信息后再交给外部模型。
